# Assaf Perfumes — website

A complete storefront for the Assaf perfume brand. It's a static site written in plain HTML, CSS and JavaScript, with no build step. The only library is **Three.js r160**, copied into `assets/vendor/three/` and used for the 3D unboxing viewer. It loads only when a viewer opens.

## Pages
| Page | File | What it does |
|---|---|---|
| Home | `index.html` | Hero with a product render (tilt, slow float, scroll parallax), a strip of moving products you can drag (tap any bottle to unbox it), a scroll showcase, collections, bestsellers, recently viewed, the brand story and newsletter signup |
| Shop | `shop.html` | Filters for collection and gender, note search, sorting and a wishlist view. The URL keeps the filters (e.g. `shop.html?family=Arrogate`, `shop.html?wishlist=1`) |
| Product | `product.html?id=…` | Size choice, quantity, add to bag or buy now, wishlist, "Unbox in 3D", notes, specs, related products, recently viewed and a sticky add-to-bag bar on mobile |
| Bag | `cart.html` + slide-out drawer | Items shown as branded boxes, quantity changes, animated removal and a progress bar toward free shipping |
| Checkout | `checkout.html` | Contact and address details for the UAE, KSA and GCC, payment by card or Tamara, form checks and an order confirmation |
| Our Story | `about.html` | Brand story, collections and values |
| Contact | `contact.html` | Contact details, contact form and FAQ |

## Interactive features
- **Unboxing:** tap any product card or the hero.
  - The card expands into a focused view that animates from the card's position.
  - A branded Assaf box opens: the lid lifts with a slight overshoot and the inner flaps fold out.
  - The bottle rises and slowly turns. Drag it, or use the arrow keys, to rotate it a full 360°.
  - Spec cards unfold in: price, size, notes, specifications and the product story.
  - Changing size updates the 3D bottle live.
  - Closing plays the whole sequence in reverse.
- **Packing:** "Add to bag" lowers the bottle, closes the lid and runs a gold Assaf seal across it.
  - The sealed box flies along a curved path into the bag icon. The bag squashes, and the count ticks up with a small pop.
  - Phones give a short vibration. A soft sound can be turned on with the speaker button in the bag; it's off by default.
  - The "+" button on cards and "Add to bag" on product pages use the same flight to the bag.
- **Quick view:** use the eye button on hover, or long-press a card on touch screens.
- **Wishlist:** tap the heart for an animated save; the saved list is at `shop.html?wishlist=1`.
- **Recently viewed:** a row on the home and product pages.
- **Search:** results update as you type. Press `/` to open it.
- **Light and dark themes:** they follow the device setting, and there's a toggle in the header.
- **Reduced motion:** with "reduce motion" on, every animation becomes a simple fade and every feature still works.
- **Accessibility:** keyboard support throughout, focus trapping in the viewer and dialogs, ARIA labels on the 3D viewer, drawer and controls, and a skip link.

All saved data (bag `assaf_cart`, wishlist, recently viewed, theme, sound) is stored in localStorage, and every read and write is wrapped in try/catch.

## Code map
| File | Role |
|---|---|
| `assets/css/style.css` | Design system: colours, spacing, corners, shadows and timing for light and dark mode, plus all components |
| `assets/js/data.js` | Product catalogue, generated by `tools/import_products.py` |
| `assets/js/bottle.js` | `ASSAF.bottle()` (product image) and `ASSAF.stage()`: the photo **ProductStage** with studio backdrop, floor shadow, light falloff, glare and tilt |
| `assets/js/main.js` | Layout, cart, wishlist, recently viewed, search, theme, fly-to-bag animation and page logic |
| `assets/js/unbox.js` | Unboxing viewer, packing, quick view and `ASSAF.ProductStage.mount3D()` (loads the 3D code on first use) |
| `assets/js/stage3d.js` | 3D ProductStage: box, bottle, lighting, shadows, rotation and the open/close/pack animations |

## Run locally
```bash
python3 -m http.server 8000
# open http://localhost:8000
```
You can deploy it to any static host (GitHub Pages, Netlify, Vercel, Cloudflare Pages) by uploading the folder. Use a host that gzips files: with compression, Lighthouse mobile scores 90+ for Performance on every page and 100 for Accessibility, Best Practices and SEO.

## Products (imported from assaf.ae)
The catalogue in `assets/js/data.js` and the photos in `assets/img/products/` (800px, plus 400px copies in `sm/`) are generated from the live store: 105 perfumes and gift sets, with prices in AED. Watches and sunglasses are left out. To refresh, run:
```bash
pip install pillow
python3 tools/import_products.py
```

## Assets to provide (and where to put them)
The site works without any of these. Each one makes the 3D view more realistic.

| Asset | Format | Where to put it | Then |
|---|---|---|---|
| **3D bottle model** for each product | `.glb` (glTF binary), Y-up, real-world proportions, bottle standing on the origin, PBR materials (glass with transmission, metal cap), under ~2 MB | `assets/models/<product-id>.glb`, e.g. `assets/models/arrogate-pink-200ml.glb` (the id is the `?id=` in the product URL) | Add the id to `"models"` in `assets/models/manifest.json` |
| **Box front artwork** | JPG or PNG, 1024×2048 (1:2) | `assets/models/box-front.jpg` | Set `"boxFront": "box-front.jpg"` in the manifest |
| **Box lid artwork** | JPG or PNG, 1024×1024 | `assets/models/box-lid.jpg` | Set `"boxLid": "box-lid.jpg"` in the manifest |
| **Logo as vector** | SVG (white or single colour) | `assets/img/logo.svg` | Lets the logo stay sharp at any size. The current `logo.png` was taken from assaf.ae |
| **Studio photos** (optional) | Transparent PNG or white-background JPG, 1600px or larger | Replace files in `assets/img/products/` (keep the file names), or re-run the importer | Sharper cards and fallback images |

Until a `.glb` is added, the 3D view shows a stand-in glass bottle: tinted with the product's colour, with a brushed-metal cap and the product name on the label. Models are scaled automatically to fit the box.
